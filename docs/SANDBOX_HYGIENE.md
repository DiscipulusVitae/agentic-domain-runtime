# Sandbox Hygiene Policy (Политика гигиены песочницы)

Данный документ описывает правила ограничения размера файлов для предотвращения появления монолитов в кодовой базе `sandbox`.

## Лимиты размера файлов

Для поддержания читаемости и облегчения поддержки кодовой базы установлены следующие ограничения на максимальное количество строк в одном файле (включая комментарии и пустые строки):

- **Файлы исходного кода** (`src/sandbox/**/*.py`) — не более **500 строк**.
- **Файлы тестов** (`tests/sandbox/**/*.py`) — не более **700 строк**.

## Автоматическая проверка

В кодовую базу встроен автоматический тест `tests/sandbox/test_hygiene.py`, который рекурсивно проверяет все Python-файлы в указанных директориях во время каждого запуска тестового набора.

Если лимит превышен, тест завершится ошибкой и выведет список файлов-нарушителей.

## Что делать, если лимит превышен?

Если файл превысил допустимый лимит строк, разработчику необходимо предпринять одно из следующих действий:

1. **Рефакторинг (Рекомендуется):** Разделить логику файла на более мелкие изолированные модули и распределить их по поддиректориям.
2. **Временное исключение (Allowlist):** В исключительных случаях, с одобрения архитектора, файл можно добавить во временный список исключений `ALLOWLIST` внутри `tests/sandbox/test_hygiene.py`. Формат добавления:
   ```python
   ALLOWLIST = {
       "relative/path/to/file.py": "Краткая одобренная причина превышения и ID задачи на рефакторинг"
   }
   ```
